# v1.0.1 post-hoc robustness supplement

Generated by `python scripts/reanalyse_revision.py`. This is CPU reanalysis of the immutable compact public tables, not new image generation or original preregistered inference. The original 20,000-resample higher-quantile headline intervals remain in their historical files and are reproduced separately. `results.json` is the shared numeric source for generated CSV, LaTeX and figures. `audit.json` records hashes, environment, counts and limits.

The 100,000-resample analysis uses linear quantiles and stable SHA-256 panel-label seeds, resampling paired blocks once per draw across metrics. Ratios and M_split are recomputed within every draw. Different seeds from the external sanity-check analysis can change CI endpoints by Monte Carlo error; point estimates are not forced.

`bonferroni_six.csv` contains exactly H, M_equal and R in each primary CFG3 W8 panel; its 99.1667% marginal intervals address only these six endpoints. All other panels, subset interactions and robustness checks are exploratory. `tiny_adjacent.csv` preserves all Tiny adjacent-anchor results. Figures have PDF, SVG and PNG versions.

Read the limitations array in results.json before population, mechanism, quality or reproducibility claims.

# FDCA Visual v1.0.0 - Initial Public Release

**Technical preprint; not peer reviewed.** Paper: *First-Divergence Consequence Analysis: From Quantization Onset to Perceptual Impact in Masked Visual Generators*.

Zenodo DOI: [10.5281/zenodo.21965747](https://doi.org/10.5281/zenodo.21965747); record: https://zenodo.org/records/21965747.

This initial release publishes theory, audited coupling/RNG/instrumentation, compact T0-P3S evidence, model-free reproduction, paper PDF/source and provenance. Within the audited Halton/W8/common-suffix scope, split incidence decreases while split-conditional perceptual consequence increases from target anchor 0.3 to 0.5, replicated on H-MaskGIT-T and H-MaskGIT-S. This is not a human-perception or architecture-universal claim.

External checkpoints, VQ/metric weights, datasets, full trajectories, external clones, environments and logs are excluded. Tier A is public/model-free; Tier B needs official assets; Tier C remains archived privately. Original code is MIT; paper, figures, tables and audit documentation are CC BY 4.0.

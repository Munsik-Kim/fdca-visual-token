# Reproducibility tiers

- **Tier A — public CPU computations:** exhaustive synthetic checks; exact replay of eight frozen block contrasts using stored semantic seeds, 20,000 draws and higher quantiles, checking both CI endpoints; two saved OOF MAE reaggregations; new 100,000-draw linear-quantile post-hoc block analysis; generated tables/figures; version-aware PDF build; source/PDF hash receipt; historical-asset, privacy and manifest validation.
- **Tier B — official external assets required:** original H-MaskGIT forwards, VQ decoding, LPIPS/DINO/classifier inference, natural-seed/common-suffix trajectories, original feature extraction and LOBO fitting. These are not replayed by the CPU reproduction script. Asset revisions and hashes are listed in the [registry](EXTERNAL_ASSET_REGISTRY.md), without redistributing weights.
- **Tier C — archived evidence not redistributed:** full trajectories/PNG corpora, complete class/base-seed manifests, seed token/coordinate identities, model-forward caches and private operational logs. Source/audit claims depending on this tier are labeled, rather than presented as independent public reproduction.

`make reproduce` retains the original inference rule. `make reanalyse` is an explicitly post-hoc supplement; its RNG mapping, inputs and environment are in `public_results/reanalysis_v1_0_1/audit.json`. Whole blocks preserve rho pairing and metric dependence. Bootstrapping estimated block means does not fully recover conditional-rollout Monte Carlo uncertainty or unavailable class clusters. Different seed rules yield small CI endpoint Monte Carlo differences; supplied sanity-check endpoints are not forced.

Install `environment/requirements-revision.txt` for figures and PDF rendering. `make paper` separately preserves the historical v1.0.0 page-count test. `make paper-revision` stages the versioned source plus generated assets, omits the revision .bbl to force BibTeX regeneration, saves the real revision PDF/bbl, and records input/output SHA-256 in `paper/build_v1.0.1.json`. It imposes no equality with the old page count and rejects undefined references/citations, missing glyphs and overfull boxes. `python scripts/build_paper.py --version 1.0.1 --check` checks the saved compile receipt without recompiling.

The document's visual review renders every new PDF page and inspects the pages as described in the final validation record. The archived v1.0.0 source/PDF and DOI metadata are preserved; no release asset or Zenodo deposition is replaced. Follow-up plans are NOT RUN. This revision performs no GPU inference, training, model-weight download or new image generation.

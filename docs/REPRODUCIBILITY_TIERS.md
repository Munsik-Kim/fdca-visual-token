# Reproducibility tiers

- **Tier A - fully public/model-free:** paper build, T0 theorem tests, gate arithmetic, block bootstrap checks, OOF diagnostic aggregation, figures/tables, manifest and privacy validation.
- **Tier B - official external assets required:** H-MaskGIT model forwards, VQ decoding, LPIPS/DINO/classifier inference and natural-seed/common-suffix rollouts. Exact assets are listed but not redistributed.
- **Tier C - archived, not redistributed:** full trajectories, full PNG corpora, model-forward caches and private operational logs. Their size, privacy burden and lack of necessity for headline model-free checks justify exclusion.

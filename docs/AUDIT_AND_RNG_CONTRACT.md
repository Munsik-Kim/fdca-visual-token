# Audit and RNG contract

Semantic keys include experiment, approximation cell, block, anchor, replicate, step, coordinate, event kind, attempt and draw ID. Reference-shared proposal draws are intentional reuse; acceptance/residual draws are branch/event specific. Registries compare duplicate multisets against an explicit allow-list. Stable sets use actual non-MASK semantics where required; selected-MASK and pre/post-clamp changes are counted separately.

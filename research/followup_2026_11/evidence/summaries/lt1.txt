FDCA LT0–LT1 실제 실행 결과

LT1 공통 완료 panel은 16 classes, arm당 32 joint paths, 8 arms로 총 256개 unit이다. 이 unit들을 독립 표본으로 세지 않고 16개 class를 재표집한다.
기술 검증: PASS; 예상 panel 완전성=True; 제외 trajectory=0; 실패 기록=0.
실제 전체 실행 비용=272.335초, 동결 hard cap=2040초 (전체 supervisor wall 기준).
LPIPS는 FP32 reference와의 출력 차이이며 품질 저하·사람 선호·packed INT8 속도 이득을 뜻하지 않는다.
전체 eligible W8: R_path=0.15319, 95% CI [0.111082, 0.201793]; split=32/32; Hamming=0.237671.
6개 단일 block에서 same-state local TV와 R 순위의 기술적 Spearman=0.942857. 이번 pilot에서는 두 순위가 대체로 일치하며 추가 선택 가치가 입증되지 않았다.

조건과 해석 단위:
H-MaskGIT-T, 실제 L=6, CFG3, 256 tokens, fixed Halton 32단계, FP32 실행, per-output-channel W8 reconstructed weights. 한 block의 W8 개입은 전체 32단계 동안 지속된다.
token Hamming/first split은 pre-clamp sampler state 기준이고 LPIPS는 공식 decoder-grid 및 RGB clamp 이후 이미지 기준이다. selected-MASK/clamp 기록은 원자료와 NUMERICAL_RECEIPT에 남는다.
R_path는 미분기 경로를 포함한 최종 LPIPS 평균, H_path는 실제 ever_split 평균, M_split,path=R_path/H_path다. seed 안 반복 → class 안 seed → class 동일 가중을 쓴다.
20,000회 paired class-cluster bootstrap, linear quantile, seed=20261029. 같은 class draw를 모든 arm과 metric에 공유했다. 탐색 CI이며 확증 p-value를 계산하지 않았다.
REF_FP32는 동일 모델 기술 대조군이다. token/image/LPIPS의 정확한 0은 SELF_CASE_PASS로 기록하며 H=0의 조건부 M은 미추정이다.
candidate에서 분기를 관측하지 못했을 때의 [0,0] bootstrap을 true no-effect의 증거로 쓰지 않는다. 실패·누락을 0으로 채우지 않았다.

이는 점추정 순위다. CI 중첩과 class별 변동을 무시한 확정 순위가 아니다.
local_tv_same_state_mean 대 R: 기술적 Spearman=0.942857 (L=6); 확증 p-value 없음.
local_mse_same_state_mean 대 R: 기술적 Spearman=0.714286 (L=6); 확증 p-value 없음.
MSE는 normalized categorical probability 차이의 평균제곱이다. logit/weight MSE가 아니며 작은 수치 자체가 수치 바닥이나 무효과를 뜻하지 않는다.
최초 분기 후에는 새로운 양자화 innovation과 기존 상태 차이의 전파가 섞인다. 이를 전부 최초 seed의 순수 후손으로 해석하지 않는다.
CDF와 empirical hazard는 실제 nullable first_split_step과 직전까지 생존한 경로 분모에서 계산했다. 분기 후 reference-state analytic h는 persistent-path hazard가 아니다.
R/H로 같은 R ranking을 재표현하는 것은 추가 selection 정보가 아니다. prospective policy/restoration gain은 아직 미검증이다.
